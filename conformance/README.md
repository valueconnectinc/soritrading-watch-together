# Conformance vectors

Language-neutral test cases. Every connector must pass all of them with its own test runner.
Expected values are written by hand — never generated by an implementation.

## `control/*.json` — control-plane tracker

The tracker turns `control` messages into a per-exchange level on the client's own monotonic clock.

```json
{
  "name": "...",
  "uses": ["binance"],
  "steps": [
    { "at": 0, "control": { ... } },
    { "at": 0, "unsupported": true },
    { "at": 1000, "expect": { "known": true, "level": { "binance": "hard", "okx": "free" },
                              "frozen": { "binance": true }, "notice": null, "acks": [ ... ] } }
  ]
}
```

- `at` — milliseconds on the client's monotonic clock. Steps are in order.
- `control` — a control state exactly as the agent sends it (event `control` or `control.state`).
- `unsupported: true` — the agent answered `control.state` with 501/404 (older agent).
- `expect` — only the listed keys are checked.
  - `level.<ex>` — `"free"`, `"soft"`, `"hard"` or `"unknown"` (no control state yet / unsupported).
  - `frozen.<ex>` — whether the exchange is frozen at `at`.
  - `notice` — the last notice (`null` when none).
  - `acks` — acknowledgements the tracker produced since the previous `expect` (then cleared), in order:
    `{ "epoch", "ex", "level" }`. Only exchanges listed in `uses` are acknowledged, once per change of level.

Rules the vectors encode:

1. A control message replaces the whole table.
2. An entry is valid while `at < receivedAt + ttlMs`. After that the level is `free` until renewed.
3. `"*"` applies to every exchange. The effective level is the higher of the exchange's own entry and `"*"`.
4. Within one `boot`, a message with a lower `epoch` than the last one is ignored. A new `boot` resets the epoch.
5. `frozen.<ex>.untilMs` is relative to when the message was received.
6. Acknowledgements: every used exchange starts at `free`. Before checking an `expect`, the runner advances the tracker
   to `at` (leases can expire without a message) — a change of level, by a message or by expiry, produces one ack
   carrying the last applied epoch. `unknown` never produces an ack.

## `sse/*.json` — Server-Sent Events parser

`{ "chunks": ["..."], "events": [{ "event", "id", "data" }] }` — feed the chunks in order; the parser must emit exactly these events
(`data` as the raw string, `id` `null` when absent). Comment lines (`:`) are ignored.

## `ops.json`

The operation names of protocol v1. Checked against the agent's definition by the agent's own test suite.
